BCI OPERATIONS 0.8.6-catalog.11 | Catalog and part photos
======================================================

RANDY
1. Extract the source ZIP into an empty temporary folder. Give Greg the
   included source folder. Do not put it inside the existing source folder.
2. After Greg builds the update, verify v0.8.6-catalog.11 beside the BCI logo.
   Already imported the catalog? You do not need to import it again.
3. To import for the first time, use Warehouse > Import Catalog as admin.
   Select the separate BCI Catalog Import - Label Window Faceplates Only.json
   file, then click Preview import.
4. Review adds and existing matches. Review any conflicts before choosing
   whether to skip those rows. Do not delete existing items to clear conflicts.
5. In Warehouse, combine Search, Brand, Category and Type to find a part.
   The Warehouse grid is text-only. Photo and zoom controls remain available
   in the work-order and estimate material pickers for eligible parts.
   A family photo is a reference; color, finish or pack size may differ.
   Parts without photos still show in search and have part details.

SEPARATE FILTERED IMPORT
3,854 parts, including 43 Signamax data faceplates with label windows.
2,386 parts reference photos; 639 fit references are documented.
The import is additive. It will not delete parts already in your database.

WHAT THE IMPORT CHANGES
- Loads the manufacturer's part list, classifications, specs, documented
  fit, source references and photo links. Identifies existing parts by
  exact manufacturer and part number and fills missing details on a unique match.
- Does not set counts, locations, prices, or historical entries. Count on-hand
  inventory from inside a warehouse grid row, and set cost and default selling
  rates separately. A new item may still need unit or pricing review.
- Catalog unit is manufacturer reference information, not a stocking or
  billing decision. If unlisted, verify the unit before pricing the item.
- Images are 512 x 512 and bundled in the app build. No external image call
  is needed. This pass does not have a photo for every part.
