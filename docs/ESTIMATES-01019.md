# BCI Operations 0.10.19: Estimates

## Install on staging first

1. Back up the current staging MariaDB database and app source. Record the running image tag and keep it available for rollback. Use the tested 0.10.18 source as the base for this changed-file overlay; do not overwrite your own environment files, Compose configuration, or storage.
2. In the **staging** BCI app database only, apply `source/sql/003_estimate_plan_storage.sql` with an authorized database admin. It adds the private drawing table without changing existing data. The app DB account needs SELECT and INSERT on this table; grants are not changed by the script. Check the database and reverse-proxy upload-size limits allow 10 MB of PDF bytes (roughly 13.4 MB of JSON on the HTTP request). The main application state will not contain MariaDB drawing bytes. Include the new table in backups.
3. Overlay the changed `source/` files as a unit, build a private 0.10.19 staging image, and recreate only the app container using the existing environment and network settings. Confirm `/api/health` and the header badge show 0.10.19. Keep your live data and production pipeline out of this test.
4. Run `npm ci`, `npm run check`, `npm test` and the staging walkthrough below. The local HTTP test uses the JSON adapter and does not prove MariaDB/Cloudflare or a particular phone works. If testing in local mode, bind only to loopback and use disposable data.

## Try it

- **Estimates → + New Estimate**. Select/create the billing client, site project and contact. Choose Site Walkthrough or Plan Takeoff. Use **Jump to** to skip between job conditions, six trades, plans, terms and review, or **Edit all answers** where appropriate. Questions save with the current revision; unsaved edits stay marked until a save succeeds.
- The downloaded Takeoff Lab runs separately in your browser from a local file. Use Open PDF, sheet calibration, Count, Route and optional reviewed matches. Export its project JSON and import it in **Plans & takeoff**. Review individual counts or route lengths, choose the scope, and use Add, Replace or Reference only. Uncalibrated routes are not imported as footage. You can attach a private original or marked-up PDF separately, mark its scope role and enter the revision. Attachments are only downloadable by authenticated staff with access to that estimate. The customer PDF records the attachment references; attach governing PDFs to the client package manually.
- Add a Copper group (e.g. two 100-foot Cat6 CMP runs). Set task hours and a matching service/explicit rate, match parts or supply a manual BOM, and pick pricing. Try an optional Fiber group and a shared rental. Set terms and review numbers. The preloaded choices are starter questions, not certified production productivity. Administrator rule versions should be released only after comparison with actual BCI work orders; the rules editor accepts JSON with a version label, calibration basis, and per-task coefficients. Use explicit refresh to apply new rules/rates to a draft.
- Allowances use custom lines and scope language, independent of unit price, T&M, fixed, ROM or NTE. The explicit project package / project ceiling live under Payment & terms. Ensure an existing customer's contractual, tax and signature requirements are satisfied before a real quote. No payment processing, automatic email, inventory issue, invoice or purchasing is added by this release.
- **Preview Client Agreement** shows a server-generated customer-only view. Use **Print / Save PDF** to save a PDF through the browser dialog. Use **Sign on this device** to capture signature, consent and name/title, or record external evidence separately. Confirm frozen accepted document and unreleased work orders. Repeat submission must not create duplicate orders. Revisions show differences and do not overwrite released work.
- Reopen legacy drafts and accepted estimates. Print an old signed one and compare it to the original. Try edit denied vs read permission, and a second client with no access to the first client's PDF. Confirm a quoted price does not shift when you reload an already accepted revision.

## Limits and rollback

- No field productivity weights, five-minute workflow target, or 9-in-10 coverage claim has been validated with actual BCI jobs. The system uses your reviewed inputs or administrator-released rules. The cut-length checks use supplied route lengths; they are not an exact optimizing reel-cut plan.
- Training/Practice Mode keeps the earlier estimator to prevent sample drafts from using live estimate endpoints.
- Plan takeoff uses a reviewed JSON transfer today rather than a drawing editor embedded within the live estimate screen. Printed agreement uses browser PDF; no customer portal or remote-sign email link. Export/download is staff-driven.
- Restore the prior image if necessary, retaining the new table and a fresh database backup first. Do not edit or drop the new drawing table to roll back code. Any 0.10.19-approved agreements need their own backup/export before reverting; do not use the older editor to modify a new-format record. If rolling back after real usage, coordinate how to retain new drafts, approvals, and released work; do not blindly restore an older database over newer records.
